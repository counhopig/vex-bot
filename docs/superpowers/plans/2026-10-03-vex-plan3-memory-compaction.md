# 计划 3：记忆与上下文压缩

依据：设计文档 §6.4、§6.5、§8.1、§8.2。

1. 建立 SQLite FTS5 索引，使用中日韩重叠双字分词；将 Markdown 标题和段落、会话用户与助手消息分块，保留来源、日期、会话。
2. 通过文件修改时间和 JSONL 字节偏移增量同步；处理删除、覆盖、截断和损坏重建。
3. 注册 `memory_search(query, limit?, scope?)`，支持 memory、sessions、all 与 BM25 排序；启动及每轮结束同步。
4. 在 `transformContext` 中按模型窗口和阈值判断压缩；保留最近完整用户轮次与工具调用/结果配对。
5. 压缩前运行不向渠道发布事件的记忆抢救工具轮，后台模型生成早期历史摘要。
6. 摘要以特殊 JSONL 条目持久化，恢复最近摘要上下文；完整原文继续用于 UI 历史与检索。
7. 覆盖中文检索、增量同步、损坏修复、工具过滤、压缩恢复、中断和静默输出测试；运行类型检查、全量测试和构建。
